ℹ️ Como usar esta abaUse esta aba para coletar os códigos de barras dos produtos que precisam de etiquetas na loja.
  1. Bipe o código ou pesquise o produto pelo nome.
  2. Segure o item para escolher o tamanho (P, M ou G) e a quantidade.
  3. Toque no quadrado ao lado do item para marcar as que já foram colocadas para impressão.
  4. Toque no ⧉ para duplicar o código e escolher outro tamanho (ex.: 2 P e 1 G do mesmo produto).
  5. Quando terminar, use Remover todos para limpar a lista.
A lista é compartilhada: todos os aparelhos veem as mesmas etiquetas e as marcações de “já imprimi”.O cadastro de produtos pode ser feito por qualquer usuário: se o código ainda não existir, o app pede o nome e cadastra na hora.
